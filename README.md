# Semantic Image Search with MongoDB and Vertex AI

A demo application that implements semantic image search using MongoDB's Vector Search and Google's Vertex AI multi-modal model. The application allows users to search through an e-commerce dataset of 44,000 fashion products using either natural language descriptions or uploading an image of a similar product.

![Semantic Image Search with MongoDB](https://github.com/user-attachments/assets/de4d0257-6021-4e6d-a9a2-16cfd870204f)

## Key Features

- **Dual Semantic Search**: Search through fashion products using natural language descriptions or by uploading an image of a similar product.
- **MongoDB Atlas Vector Search**: Uses [MongoDB Atlas Vector Search](https://www.mongodb.com/products/platform/atlas-vector-search) to efficiently store and query high-dimensional embeddings.
- **Google Vertex AI Integration**: Uses [Google's Vertex AI multi-modal model](https://cloud.google.com/vertex-ai/generative-ai/docs/embeddings/get-multimodal-embeddings), where both image and text embeddings exist in the same semantic space with same dimensionality.
- **Large Fashion Dataset**: Uses the [Fashion Product Images Dataset](https://www.kaggle.com/datasets/paramaggarwal/fashion-product-images-dataset) from Kaggle, containing 44,000+ fashion products with detailed attributes and images.

## Project Structure

The repository consists of two main applications:

1. **Server**: A Node.js/Express backend application that handles data processing and API endpoints.
2. **Frontend**: An Angular application that provides the user interface for semantic search.

## Prerequisites

- Node.js and npm installed
- Angular CLI installed
- MongoDB Atlas account
- Google Cloud Platform account with Vertex AI API enabled

## Setup Instructions

### Server Setup

1. Navigate to the server directory:

   ```bash
   cd server
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Create a new file named **.env** in the server directory:

   ```bash
   touch .env  # For Unix-based systems
   # or manually create a new file named .env in your text editor
   ```

4. Add your environment variables to the **.env** file:

   ```
   MONGO_DB_CONNECTION_STRING=your_mongodb_connection_string
   GOOGLE_PROJECT_ID=your_google_project_id
   GOOGLE_CLIENT_EMAIL=your_google_client_email
   GOOGLE_PRIVATE_KEY=your_google_private_key
   GOOGLE_LOCATION=your_preferred_location
   ```

5. Start the server:

   ```bash
   npm start
   ```

   The server will run on port 3000.

6. Import the product dataset in MongoDB:

   Call the following endpoint via Postman or a similar tool:

   ```
   POST http://localhost:3000/api/v1/import-data-to-database
   ```

   This will populate the database with all 44,000 products from the dataset.

7. Create a Vector Index in MongoDB Atlas with the following settings:

   - Index name must be: `vector_index`
   - Specify the path as: `image_embedding`
   - Set `numDimensions` to **1408** (This should match the dimensionality of the embeddings generated by the Vertex AI multi-modal model)

   This configuration is required as the code expects these specific settings.

8. Generate embeddings for the products:

   Call the following endpoint via Postman or a similar tool:

   ```
   POST http://localhost:3000/api/v1/create-embeddings
   ```

   This will generate embeddings for all products.

   This process runs in batches of 50 products and may take approximately 1 hour to complete for the entire dataset. The batch size can be modified by updating the `batchSize` property in the code.

### Frontend Setup

1. Navigate to the frontend directory:

   ```bash
   cd frontend
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the Angular application:

   ```bash
   npm start
   ```

   The frontend will run on port 4200.

   At this point, both the server (3000) and frontend (4200) apps should be running.

4. Open the application in your browser:

   Open your browser and navigate to http://localhost:4200.

   You can now explore **semantic image search** using the dataset.

## Technical Details

- Backend: Node.js with Express
- Frontend: Angular
- Database: MongoDB
- Embedding Model: Google Vertex AI multi-modal model
- Dataset: E-commerce product dataset with 44,000 items
